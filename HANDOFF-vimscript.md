## The differential-test oracle

- `python3 -I tools/vimscript_oracle.py [crates/rim/src/editor/script/cases/X.vim]` runs every script of `cases/*.vim` in `nvim --headless -u NONE -i NONE -n` and writes `*.golden`. Cases separated by lines `"---`. Each script is `:source`d with its own `-c`. `*.typed.vim`: each line is typed at the `:` prompt with `feedkeys()`. A case that loops forever times out the oracle (30 s): guard loops with a counter.
- `golden.rs` runs each case through `Editor` (`Messages::redir` collects shown text) and compares. `KNOWN` lists differing case numbers: **empty in every corpus now**. `RIM_GOLDEN_SHOW=1 cargo test -p rim -- _cases_match` prints every difference.
- Corpora (cases): `range`, `typed` (48), `cmd` (139), `bar`, `let` (354), `funcs`, `expr` (64), `args` (879: every builtin with one wrong-typed argument per position, the others `1`; found `strridx` third argument), `sort` (816: `sort()`/`uniq()` 2 to 400 items, message counts), `valid` (461: valid values, buffer, marks, registers, `exists`, `has`; see vimscript.md for what was left out on purpose), `triple` (2500: 3 wrong-typed arguments, all combinations), `double` (1971: two extreme values at positions 0/1, 1/2, 0/2), `mixed` (1466: two wrong-typed arguments together, all pairs of 5 types at positions 0/1 and 1/2), `extreme` (1813: extreme valid values at every position: `''`, 0, -1, the largest and smallest number, multibyte, a newline, `[]`, `{}`, `1.0e308`, `-0.0`, `inf`, `nan`), `edge` (667: every builtin with 5 wrong-typed arguments, number/string literals, operators, `:let`/`:unlet` on `v:`/`&`/`@`/`$`, `:echo*`/`:execute`/`:call` oddities; generated once by a script, now plain cases).

## Neovim facts worth remembering

- `DOCMD_VERBOSE` is set for sourced files, `:execute` and `-c`, **not** typed `:` lines; it adds `: {command line}` to `do_one_cmd` errors and makes a backwards range `E493` (typed ones ask).
- `msg_scroll` is on during a command line (typed or sourced), so `msg_strtrunc` does not cut there; it cuts messages of Normal mode commands.
- `redir_write` in a typed command pads to `msg_col`; `:redir` closes the previous redirection (file, register, variable).
- `emsg()` under `emsg_silent` does not set `did_emsg`; `emsg` makes `global_busy` 2, so `:g` stops.
- `echo`/`execute` treat `"` as the start of the next string, `let`/`if`/`call` as a comment.
- `ex_unletlock`: a name that fails to parse or has trailing characters breaks the loop with `nextcmd` NULL (rest of the line dropped); after the first error names are only skipped.
- `get_name_len` gives `E15` for a name that is none when something follows; a curly name that cannot be expanded is `E475` in `list_arg_vars`.
- `tv_list_find_index`: an out-of-range negative index becomes 0 (first item), a positive one fails.
- `:for` keeps a pointer to the *next item*; `sort()` relinks items (the loop follows the item), `reverse()` swaps links in place, `uniq()`/`filter()` drop items (the watcher moves to the next).
- `finish` only stops reading further lines; commands after `|` on the same line still run.
